### CTX-0038 — HERE APIs (*.hereapi.com) only accept TLS 1.2 with AES-GCM or SHA-256 cipher suites, which platform TLS lacks below Android 5; Net therefore routes *.hereapi.com through bundled Conscrypt on API < 21 (same trust manager), so HERE search and routing work on Android 4.x (verified on API 19). Other hosts keep the platform TLS path. Failures still fall back to OpenStreetMap with the reason in Nav.hereError. A built-in key for local builds comes from here.apiKey in git-ignored local.properties; the Settings key overrides it.

### CTX-0046 — On XY/PVE acloud head units (AC8317) the factory radio com.acloud.stub.localradio exposes an exported, permissionless RadioService: StradaOS controls the tuner with startService(action com.android.xygala.ACTION_CONTROL_RADIO, extra method=method_open|method_close|method_seekUp|method_seekDown|method_setFreq(param_freq)|method_band(method_setband)). Frequencies are in kHz for both bands (FM 101.1 MHz = 101100, AM 522); the factory app stores FM in 0.1 MHz but multiplies by 100 before calling the service. seekUp is 'next station'. ### CTX-0048 — On XY/PVE AC8317 units the FM tuner's sound enters through the chip's AVIN analog input. It is opened by com.autochips.backcarapp BackCarService when it receives broadcast xy.android.galaxradio.setaudiotoradio (extras fm=setaudiotoradio, isToGps=false), about 1 s later, and closed by xy.android.galaxradio.setaudiotogps (fm=setaudiotogps).
